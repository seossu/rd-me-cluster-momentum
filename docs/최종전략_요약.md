## 4. "사실상 시총 전략 아니냐"에 대한 답

| 검증 | 결과 |
|---|---|
| rd_me 순위 ↔ 시총 순위 상관 | **+0.016** (R&D 금액 순위와는 +0.811) |
| 순위 변수를 1/시총으로 교체 | Sharpe 1.28 → **0.28** |
| 순위 변수를 시총으로 교체 | Sharpe 1.28 → **0.35** |
| 시총 중립화 rd_me (log rd_me를 log 시총에 회귀한 잔차) | Sharpe **1.20** (거의 유지) |
| SMB 로딩 | +0.014, p = 0.86 |
| 롱·숏 레그 중앙 시총 | 1.8조 vs 1.2조 |

**월간 리밸런싱의 근거**: R&D 값은 3월 47% · 4월 15%에 갱신되고 나머지 달은 거의 변하지 않는다. 월간 갱신의 가치를 분해하면 시총 갱신을 막았을 때 Sharpe 1.28 → 1.08인 반면, **모멘텀·군집 갱신을 연 1회로 묶으면 1.28 → 0.52**로 떨어진다. 월간으로 도는 것은 R&D가 아니라 동조 집단과 모멘텀이다.

분모가 월간으로 움직이는 것은 밸류에이션 비율의 표준 구성이다 (B/M도 장부가는 연 1회, 주가는 매일). Asness & Frazzini(2013)는 가치비율의 주가를 최신값으로 갱신하는 편이 성과가 낫다는 것을 보였다.

분기보고서 기반 TTM R&D도 실제 수집해 검증했으나(1,285건, 100종목), 롱·숏 30종목 중 27종목이 동일해 실익이 없었다.

## 5. 반드시 공개할 한계

1. **Louvain seed 의존성** — seed 0/1/2에서 Sharpe 1.28 / 1.16 / 1.09. 헤드라인은 seed 0이다.
2. **파라미터가 국소 최대값** — 시총컷 30%, 유동성 하위 10%, 트리창 104주, 종목수 30, 모멘텀 11개월 모두 이웃값보다 우수한 지점이며 사후적으로 선택됐다.
3. **2020년 의존** — 2020년 +52.5%가 모든 10년 구간에 포함된다. 제외 시 CAGR 3~4%p 하락.
4. **모멘텀 창의 '2개월'은 사후 선택** — 방향(최근 구간 제외)은 Novy-Marx(2012) 에코 효과와 Jegadeesh(1990) 단기 반전으로 지지되나, 정확히 2개월이라는 값은 문헌이 정하지 않는다. 창을 통째로 뒤로 미루면 오히려 악화(1.07→0.99→0.99→0.79)하므로, 핵심은 '늦게 보는 것'이 아니라 '먼 과거를 유지한 채 최근 1개월을 창에서 빼는 것'이다.
5. **숏 선택 버그 수정 이력** — 2026-09-24 이전 산출물은 pandas `Index.difference()`의 가나다순 정렬 때문에 숏이 'rd_me 하위 60종목 중 이름순 앞 30개'였다. 현재는 진짜 하위 30종목이며, 이전 수치는 모두 폐기됐다.
6. **군집은 완벽하지 않다** — 정밀도 24.5% / 재현율 21.1% (랜덤 7.1% 대비). 산업분류가 못 잡는 연결을 보완하는 장치이지 대체물이 아니다.
