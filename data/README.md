# 데이터

원본 데이터는 용량(최대 약 113MB)과 데이터 제공처 라이선스 때문에 저장소에 포함하지 않았습니다.
아래 파일을 이 폴더(`data/`)에 같은 이름으로 넣으면 스크립트가 그대로 실행됩니다.

## 메인 스크립트(`rd_me_MST_전략.py`)용

| 파일 | 내용 |
|---|---|
| `2012_2026_일별_코스피코스닥_시가총액_거래대금_비영업일제외.csv` | 일별 시가총액 (백만원), 종목명 열 |
| `60일거래대금.csv` | 일별 거래대금 (원), 종목명 열 |
| `수정주가(현금배당포함).csv` | 일별 배당 포함 수정주가 |
| `수정주가(현금배당포함)2010.csv` | 2010년 이전 구간 보완용 수정주가 |
| `rnd_merged.parquet` | DART 사업보고서 연구개발비 (`ticker, fy, rnd_won, ratio, rcept_dt, name`) |
| `재무제표.csv` | 매출액. R&D 파싱값 검증(F1)에 사용 |
| `universe_codes.csv` | 종목코드(`code6`) ↔ 종목명(`name`) |
